# @mgamadeus/ddd-admin-ui — documentation

Skeleton. The chapters below are filled when the blocks arrive.

1. **Concepts** — runtime layers (pure, react, browser, primitive, block, adapter) and the entries.
2. **Host setup** — stylesheets, `tokens.json`, the layer scale, dark mode, the provider and its adapters.
3. **Translations** — the store, `m()` on the server, `i18n-keys.json` and the host's translation export.
4. **Primitives** — the component set and its overlay layers.
5. **Blocks** — list, page, form, translations, media, glass, data.
6. **Next adapters** — the URL write queue and URL state.
7. **Standards** — rules every admin screen built on these blocks follows.
